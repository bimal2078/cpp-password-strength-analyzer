# C++ Password Strength Analyzer 🔐

A beginner-friendly cybersecurity project built using C++ and Object-Oriented Programming (OOP).

This program analyzes a password based on its length and character types, then assigns a simple strength score.

## Features

- Checks password length
- Detects uppercase letters
- Detects lowercase letters
- Detects numeric digits
- Detects special characters
- Calculates a password score out of 5
- Classifies passwords as Weak, Medium, or Strong

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- C++ Standard Library

## OOP Concepts Practiced

- Classes and Objects
- Encapsulation
- Access Modifiers
- Member Functions
- Conditional Statements
- Loops

## How to Run

### Requirements
- C++ compiler (G++)
- Visual Studio Code or any C++ IDE

### Compile

```bash
g++ main.cpp -o analyzer
```

### Run on Windows

```bash
.\analyzer
```

## Example

Test password: `Cyber@2026`

Expected result:

```text
Score: 5/5
Strength: STRONG
```

## Disclaimer

This is an educational project. The scoring system is a basic demonstration and does not represent a professional password security assessment.

Do not enter real or personal passwords into this program.
